# AppLoomaWebRTC

Prebuilt WebRTC framework used by the [AppLooma RTC](https://applooma.dev) iOS
SDK.

**You do not need this package directly.** Depend on
[AppLoomaRTC](https://github.com/apploomadev/iOS-SDK), which pulls it in.

It is published separately because Swift Package Manager resolves binary
dependencies as their own packages.
